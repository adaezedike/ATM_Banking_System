
# ATM Banking System

## Overview

A console-based ATM banking application developed using Java.

This is my first Java project as I rebuild my programming skills and work towards becoming a Java Backend Developer.

## Features

- Check account balance.
- Withdraw money.
- Deposit money.
- Validate transaction amounts.
- Prevent withdrawals exceeding available funds.
- Maintain account balance between transactions.
- Menu-driven interface.

## Technologies Used

- Java
- Scanner
- Methods
- Conditional statements
- Switch statements
- While loops

## Java Concepts Practised

- Methods and parameters
- Return values
- Variable scope
- Passing objects between methods
- Input validation
- Program flow control

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the application:

   `javac Main.java`

5. Run the application:

   `java Main`
